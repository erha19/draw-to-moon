# 画到月亮 · 一笔滚月

工笔重彩月夜风格的单次绘画小游戏。**画一个圆 → 抬手生成 3D 月亮 → 自动滚动 → 距离结算 → 收藏模型与海报。** 不需要倒计时、连续画圈、补充推进或手动确认出发。

原生 JavaScript、Canvas、SVG，无第三方运行依赖。

在线试玩：<https://erha19.github.io/draw-to-moon/>

公开仓库：<https://github.com/erha19/draw-to-moon>

## 启动与访问

需要 Node.js 18 或更新版本：

```sh
git clone https://github.com/erha19/draw-to-moon.git
cd draw-to-moon
npm start
```

访问 http://localhost:4173 。服务监听 `0.0.0.0:4173`；同一 Wi-Fi 的手机使用电脑局域网 IP。公网分享需部署到 HTTPS 静态站点；本地地址不保证外网可达。部署 HTML、CSS、应用 JS（包括 `moon3d.js`）与 `assets/` 即可，无需构建。`server.js` 仅用于开发预览。

## GitHub Pages 发布

推送到 `main` 后，`.github/workflows/pages.yml` 会先运行单元测试和 JavaScript 语法检查，再将页面、应用脚本、样式和 `assets/` 发布到 GitHub Pages。也可以在仓库 Actions 页手动运行 `Deploy GitHub Pages`。

仓库 Settings → Pages 的发布来源为 **GitHub Actions**。所有资源和分享链接都保留 `/draw-to-moon/` 子路径，无需配置域名或安装依赖。

## 当前玩法

- 单指画一个完整圆，顺逆时针皆可，抬手后自动生成立体月亮。
- 直线、明显八字、太小的圈不出发；提示后可以重新画。可判定的歪圆仍可出发。
- 月亮沿山径自动滚动，圆度越高距离越远；不规则月亮会颠簸。约 1 秒成形，加 8–14 秒滚动。
- “直接看结果”只跳过动画，不改变距离。切后台暂停，返回自动继续，无需额外确认。
- 结算可以拖动旋转自己的 3D 月亮，下载 OBJ 网格、生成「送你一颗中秋的月亮」1080×1440 PNG 祝福海报，或发送距离挑战链接。
- 自动在本机保留上一颗月亮及最远纪录；首页“查看我收藏的月亮”可恢复模型与海报。
- 没有真实全国成绩分布，**不显示虚构的“击败全国 99%”**。当前展示圆度称号、距离、个人纪录，并标注全国排名尚未开放。

## 新规则 moon-roll-v2

圆度维持 80% 圆周贴合与 20% 闭合评分，等弧长重采样 64 点，最低直径为画布短边 30%。

令 `q = 圆度 / 100`：

- 最终距离 `D = 40 + 1960 × q³` 米。
- 自动滚动时长 `T = 8 + 6 × q` 秒。
- 时刻 `t` 的距离为 `D × (2u − u²)`，其中 `u = clamp(t / T, 0, 1)`。

这些是确定性的游戏参数，不是刚体物理测量。绘画速度、屏幕像素密度、渲染帧率、跳过动画都不额外影响距离。相同圆度可能获得相同距离；轮廓决定模型外形和颠簸视觉。旧版竞速成绩保留在旧存储键中，不与新距离纪录混排。

## 模型与保存

`moon3d.js` 根据归一化手绘轮廓建立封闭 3D 网格（450 顶点、896 三角面），Canvas 软件投影绘制立体光照和月坑，不是把统一球体覆盖在轨迹上。结算支持绕轴旋转。

OBJ 导出包含轮廓几何及法线，可在 Blender 等三维软件中打开。当前月坑、金色和光照为程序表面表现，OBJ 不包含材质纹理或月坑位移。海报 PNG 保留最终带光照的外观。

本地存储不可用时仍可玩、下载模型和海报。浏览器分享面板是否含“保存图片”由设备决定；下载或分享调用完成不代表已保存到相册。

## 代码与测试

- `engine.js`：画圈判定、单次自动滚动、距离与称号。
- `moon3d.js`：手绘轮廓建模、3D 渲染、OBJ 导出。
- `app.js`：四页流程、触摸输入、自动播放、收藏、分享、声音与减少动态效果。
- `poster.js`：保留真实 3D 月亮的中秋赠月海报；桂花、祥云、细金边框与祝福文案，分享图不强调成绩。
- `index.html` / `style.css`：古典月夜布局和响应式界面。
- `assets/`：原创 SVG 插画源文件，见其中 README。

```sh
npm test
npm run check
```

浏览器验收使用外部 Playwright 和已安装的 Chrome，不给游戏增加依赖：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node tests/browser.mjs
```

可通过 `BROWSER_CHANNEL`、`GAME_URL` 调整环境；截图输出 `/tmp/roll-*.png`。

分享图主题为「送你一颗中秋的月亮」，祝福语为「愿你所念皆圆满，所行皆坦途。」以及「愿此刻的月光，照亮每一个想念。」海报仍使用玩家自己的立体月亮，不添加虚构排名或技术地址。900×900 独立渲染的模型图像合成到 1080×1440 PNG，不受当前视口大小影响。

首页改为居中的一体式月夜场景；绘画、滚动、结算、海报预览分别以 100dvh 容器自适应，主要操作和内容在一个视口内展示。海报使用 object-fit: contain 保持完整比例，不裁切图像、不嵌套滚动。
